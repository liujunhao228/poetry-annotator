# 标注窗口性能优化说明

## 问题描述

原有标注编辑器在处理包含大量情感标签（100+ 个）的诗词时，存在以下性能问题：

1. **渲染缓慢** - 每个句子都要渲染所有情感标签的复选框
2. **UI 卡顿** - 当诗词有多个句子时，复选框数量可达数百个
3. **查找困难** - 用户难以在大量标签中快速定位需要的标签

## 优化方案

### 1. 标签分组折叠展示

将情感标签按一级类别分组（如"自然山水"、"宴饮节庆"等），默认折叠所有分组，用户按需展开：

```python
# 分组结构示例
{
    "自然山水": ["山水之乐", "自然奇观", "物我交融", ...],
    "宴饮节庆": ["宴饮欢庆", "节庆活动", "市井欢聚", ...],
    "功名仕途": ["求取功名", "金榜题名", "落第痛苦", ...],
    ...
}
```

**性能提升：**
- 初始渲染时只渲染分组标题，不渲染复选框
- 展开分组时才动态渲染该组的复选框
- 折叠时移除复选框，释放内存

### 2. 标签搜索过滤

添加搜索框，支持快速过滤标签：

```
搜索框：[输入"山水"] → 只显示包含"山水"的分组
```

**功能特性：**
- 实时搜索，输入即过滤
- 自动展开匹配的分组
- 一键清除搜索

### 3. 快捷标签区

显示前 8 个常用标签，支持一键添加：

```
快捷：[山水之乐] [自然奇观] [物我交融] [田园劳作] ...
```

### 4. 延迟渲染策略

```
初始状态：
┌─ 句子 1: xxx ────────────┐
│ 主要情感：[下拉框]        │
│ 📁 自然山水 (9 个) [展开]  │  ← 只渲染标题
│ 📁 宴饮节庆 (8 个) [展开]  │  ← 只渲染标题
│ 📁 功名仕途 (9 个) [展开]  │  ← 只渲染标题
└──────────────────────────┘

展开后：
┌─ 句子 1: xxx ────────────┐
│ 主要情感：[下拉框]        │
│ 📁 自然山水 (9 个) [折叠]  │
│ ├─ [✓] 山水之乐          │  ← 动态渲染
│ ├─ [ ] 自然奇观          │
│ └─ [ ] 物我交融          │
│ 📁 宴饮节庆 (8 个) [展开]  │
└──────────────────────────┘
```

## 用户体验改进

### 操作流程优化

**优化前：**
1. 打开标注编辑器
2. 在 100+ 个复选框中查找需要的标签
3. 滚动查找 → 眼晕

**优化后：**
1. 打开标注编辑器（界面清爽）
2. 方式 A：搜索框输入关键词 → 快速定位
3. 方式 B：展开对应分组 → 选择标签
4. 方式 C：点击快捷标签 → 一键添加

### 视觉优化

- 分组标题显示标签数量：`📁 自然山水 (9 个)`
- 展开/折叠按钮清晰可见
- 搜索框支持一键清除
- 快捷标签区横向排列

## 向后兼容性

- 支持字典格式（直接使用）
